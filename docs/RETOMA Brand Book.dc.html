Sistema · elemento gráfico

A Linha

Traço horizontal contínuo com uma marca vertical por dia, todas de altura idêntica. A linha de base nunca é cortada e nunca reinicia.

01 · continuidade

A linha nunca é cortada

A linha de base nunca é cortada e nunca reinicia. Nada do que já foi conquistado é apagado por um dia ruim.

02 · sem veredito

Dia de aposta é vazado, não vermelho

O dia com aposta aparece como marca vazada em Névoa. Não existe verde de sucesso nem vermelho de erro: Brasa é exclusivo de crise e segurança.

03 · altura constante

A altura jamais varia

As marcas dos dias com registro têm altura idêntica. No instante em que a altura varia conforme desempenho, vira gráfico financeiro. Só o dia sem registro é mais curto.
